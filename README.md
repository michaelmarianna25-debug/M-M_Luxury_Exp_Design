# Luxury Guest Experience Design

Οδηγίες ανεβάσματος στο GitHub Pages:

1. Άνοιξε το repo `MM_Luxury_Exp_Design` στο GitHub.
2. Πάτα Add file → Upload files και σύρε μέσα: `index.html`, `.nojekyll` και τον φάκελο `assets` (με τις 9 εικόνες).
   Αν οι εικόνες υπάρχουν ήδη στο repo, ανέβασε μόνο το `index.html` (αντικαθιστά το παλιό).
3. Commit changes.
4. Settings → Pages → Source: Deploy from a branch → main / (root).
5. Σε 1-2 λεπτά το site είναι στο https://michaelmarianna25-debug.github.io/MM_Luxury_Exp_Design/
